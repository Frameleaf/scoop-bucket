# Frameleaf Scoop bucket

Scoop manifest for [Frameleaf Desktop](https://frameleaf.app/download/), the Windows app for Frameleaf, a self-hosted
photo and video library. Frameleaf is in beta.

```powershell
scoop bucket add frameleaf https://github.com/Frameleaf/scoop-bucket
scoop install frameleaf/frameleaf
```

Source code: [Frameleaf/frameleaf-desktop](https://github.com/Frameleaf/frameleaf-desktop) (AGPL-3.0). Questions:
support@frameleaf.app.
